# StudyMate AI

StudyMate AI is an AI-powered study assistant developed as part of
a 45-day Artificial Intelligence and Generative AI internship project.

## Features

- Note Management
- Text Processing
- Keyword Extraction
- Automatic Summarization
- Quiz Generation
- Performance Analytics
- Machine Learning
- AI Assistant
- Generative AI
- Interactive Dashboard

## Technologies

- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- Streamlit
- Generative AI API

## Project Development

This project is developed progressively over 45 days.

Each development stage is documented through GitHub commits.
